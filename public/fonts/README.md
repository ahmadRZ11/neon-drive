# Fonts

## What is here

| File | Family | Role |
| --- | --- | --- |
| `pricedown-bl.woff2` | Pricedown Bl | **Display** — every headline, project title, stat figure, nav wordmark |
| `rage-italic.woff2` | Rage Italic | **Script accent** — hero tagline, one word in the About pull quote |
| `signatur.woff2` | Signature | **Sign-off** — the name in the footer, nothing else |

The original `.ttf` files are kept alongside. Only the `.woff2` versions are
loaded (277 kB → 114 kB, a 59% saving).

## How they are wired

`app/layout.tsx` loads all three with `next/font/local`, which self-hosts and
hashes them into `/_next/static/media`. Each exposes a CSS variable that
`app/globals.css` maps to a theme token:

```
--font-pricedown  ->  --font-display    ->  font-display / the `display` utility
--font-rage       ->  --font-script     ->  the `script` utility
--font-signatur   ->  --font-sign       ->  the `signature` utility
```

### Two things that will bite you

**Never put `"Arial Black"` in a `fallback` array.** The CSS minifier parses
`Black` as a colour and emits `Arial #000`, which makes the whole `font-family`
declaration invalid — headlines then silently fall back to the body font with no
error anywhere. Quoted names inside `globals.css` are safe; the `fallback`
option is not.

**Pricedown's cap-height is 0.639em** against a 1.216em content box. The
`display` utility uses `line-height: 0.74` so stacked lines sit cap-to-cap. Any
headline that *wraps* needs that loosened locally (`leading-[0.86]`) or the
lines collide.

## Why body text is not set in these

All three are display faces. Pricedown's chamfers turn to mush below ~16px, and
neither script is readable at paragraph size — the type specimen made that
obvious. So Pricedown takes every headline down to about 30px, the scripts are
used three times in total, and **Bebas Neue** (HUD micro-labels) and **Space
Grotesk** (body copy) carry everything smaller. That is what keeps the page
looking art-directed rather than costumed.

## Licensing — worth checking before you publish

These came without licence files, and web embedding is a separate grant from
desktop use:

- **Pricedown** — Ray Larabie. Widely distributed as freeware and the usual
  choice for this look. Confirm the EULA covers `@font-face` embedding.
- **Rage Italic** — the copyright string reads *Esselte Corporation 1997,
  portions Microsoft*. This is a commercial typeface that ships bundled with
  some Microsoft software. Bundled desktop rights almost certainly **do not**
  include webfont embedding. This is the one to verify.
- **Signature** — no copyright string beyond "Generated by Fontographer 3.5",
  so its provenance is unknown.

Swapping any of them is a one-line change in `app/layout.tsx`.
